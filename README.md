# MT Screen Recorder

Windows için ücretsiz, filigransız ekran kaydedici. Kayıt ve medya işlemleri yerel çalışır; lisans, reklam, özellik kilidi veya telemetri bulunmaz.

## İndir / Download

[Son sürüm / Latest release](https://github.com/dangermtster-beep/MT-Screen-Recorder/releases/latest)

- **Setup:** `MT_Screen_Recorder_Setup_1.0.0.exe`
- **Portable:** `MT_Screen_Recorder_Portable_1.0.0.zip`
- **Doğrulama:** Setup SHA-256 ve dosya boyutu `latest.json` içindedir.

Windows 10/11 64-bit. Python veya FFmpeg kurulumu gerekmez. Setup yönetici izniyle Program Files altına kurulur. Portable ZIP'i tamamen çıkarıp `MT Screen Recorder.exe` dosyasını çalıştırın.

## Özellikler

- Ekran, pencere, bölge ve monitör kaydı
- Webcam ve köşe yerleşimi; mikrofon ve sistem sesi
- Duraklat/devam, sistem tepsisi ve küçük kayıt kontrol paneli
- Ekran görüntüsü önizlemesi, dosya galerisi ve medya araçları
- Sekiz tema; Dağ & Yol, Sinematik Lens ve Neon Dalgalar dahil
- Yerel kayıt kurtarma ve GitHub güncelleme doğrulaması

Ayarlar ve loglar `%LOCALAPPDATA%\MT Screen Recorder` altındadır. Yeni kullanıcılar için medya varsayılanları Videos/Pictures altındaki `MT Screen Recorder` klasörleridir. Mevcut özel klasör ayarları korunur.

## Test durumu / Validation

Yerel kaynak ve paket kontrolleri, gerçek ikinci monitör/ses kaydı ve tema/tek-instance testleri yapıldı. Temiz Windows kurulumu/kaldırması ve iki gerçek sürüm arasında kurulum güncellemesi henüz manuel kabul bekliyor. Ayrıntılar Release notlarında bulunur.

This repository distributes application releases. Recording and media processing are local; internet is used for update checks/downloads.
